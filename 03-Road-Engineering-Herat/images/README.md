# Road Engineering Project Images

This folder contains selected engineering drawings and visual outputs from the academic road engineering project in Herat, Afghanistan, developed using Autodesk Civil 3D and AutoCAD.

The images document the geometric design, route configuration, earthwork analysis, and traffic signage planning of the approximately 12.1 km road.

## Available Images

| Image | Description |
|---|---|
| [Road Alignment Overview](road-alignment-overview.png) | Overall road alignment on the topographic map. |
| [Detailed Road Alignment Plan](detailed-road-alignment-plan.png) | Detailed horizontal alignment, curve parameters, and site constraints. |
| [Vertical Alignment Profile](vertical-alignment-profile.png) | Longitudinal road profile showing existing terrain and proposed design elevations. |
| [Road Cross-Sections](road-cross-sections.png) | Selected cross-sections illustrating roadway geometry and earthwork conditions. |
| [Mass Haul Diagram](mass-haul-diagram.png) | Original mass haul diagram illustrating cumulative earthwork volumes along the route. |
| [Adjusted Mass Haul Diagram](adjusted-mass-haul-diagram.png) | Adjusted mass haul diagram showing earthwork balancing and material disposal planning. |
| [Road Signage Plan](road-signage-plan.png) | Traffic signage layout, including regulatory and warning signs. |
