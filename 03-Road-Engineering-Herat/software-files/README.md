# Road Engineering Software Files

This folder contains the original CAD files associated with the academic road engineering project in Herat, Afghanistan, developed using Autodesk Civil 3D and AutoCAD.

## Available Files

- **[Civil 3D Final Design](Civil%203d-Last%20design.dwg):** Final Civil 3D road design model.
- **[AutoCAD Final Design](Auto%20Cad-Last%20desing.dwg):** Final AutoCAD engineering drawings.
- **[Original Site Boundary](Boundary-Fall%202022.dwg):** Original site boundary drawing used as a reference for the road design project.

## Software Requirements

- Autodesk Civil 3D
- Autodesk AutoCAD

For visual previews of the engineering drawings, refer to the [Project Images](../images/) folder.

These files are provided for academic reference and portfolio demonstration purposes.
