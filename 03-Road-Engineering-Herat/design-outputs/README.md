# Road Engineering Design Outputs

This folder contains selected engineering calculations, design outputs, and supporting technical documentation from the academic road engineering project in Herat, Afghanistan.

## Available File

| File | Description |
|---|---|
| [Design Outputs.zip](Design%20Outputs.zip) | Compressed archive containing selected engineering calculations and design outputs. |

## Included Design Outputs

- Horizontal and vertical alignment calculations
- Curve parameters and stake-out tables
- Longitudinal road profiles and cross-sections
- Earthwork volume and cut-and-fill calculations
- Original and adjusted mass-haul (Brückner) diagrams
- AASHTO-based pavement design calculations
- Quantity takeoff and cost estimation
