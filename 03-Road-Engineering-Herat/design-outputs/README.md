# Road Engineering Design Outputs

This folder contains selected engineering outputs from the road design project, including:

- Horizontal and vertical alignment calculations.
- Curve and stake-out tables.
- Road profiles and cross-sections.
- Earthwork volume calculations.
- Mass-haul (Brückner) diagrams.
- Pavement design calculations.
- Quantity takeoff and cost estimation.

These materials illustrate the engineering methods and results developed during the project.
