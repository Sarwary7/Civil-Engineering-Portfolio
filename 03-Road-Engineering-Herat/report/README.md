# Road Engineering Reports

This folder contains the original academic group report and an English technical summary focusing on my individual contribution to the road engineering project in Herat, Afghanistan.

## Available Documents

- **[English Report Summary](Road-Engineering-Report-Summary.pdf):** A concise technical summary of my individual road design, including design criteria, horizontal and vertical alignment, earthwork analysis, pavement design, drainage, quantity takeoff, and cost estimation.

- **[Full Group Report (Persian)](Road-Engineering-Full-Group-Report-FA.pdf):** The original academic group report containing detailed engineering calculations, design methodologies, technical drawings, tables, and project results.

The English summary is recommended as the starting point for international reviewers, while the original Persian report provides comprehensive supporting documentation.
