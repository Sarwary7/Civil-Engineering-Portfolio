# Project Report

This folder contains the original academic report for the Water Distribution Network Design project in West Saadat Abad, Tehran.

**Report Information:**
- **Document:** Final Group Project Report
- **Language:** Persian
- **Course:** Water and Wastewater Engineering
- **University:** Amirkabir University of Technology (AUT)
- **Academic Year:** 2024–2025
- **Team:** Group project completed by three students

The original PDF report will be uploaded to this folder.

The report documents the study area, design criteria, population forecasting, water demand estimation, network layout, hydraulic calculations, EPANET modeling, pump selection, storage design, and water quality analysis.
