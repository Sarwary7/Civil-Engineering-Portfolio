# Water Distribution Network Design Report

This folder contains the technical documentation for the Water Distribution Network Design project in West Saadat Abad, Tehran, Iran.

## Report Information

- **Project Type:** Team Academic Project (3 students)
- **Course:** Water and Wastewater Engineering
- **University:** Amirkabir University of Technology (AUT)
- **Academic Year:** 2024–2025
- **Design Reference:** Iranian Publication No. 117-3

### 2. Full Technical Report (Persian)

The original 57-page academic group report documenting the engineering design process, detailed calculations, and hydraulic simulations.

[View Full Technical Report (Persian)](Water-Distribution-Full-Report-FA.pdf.pdf)

## Technical Coverage

- Terrain modeling and elevation data extraction using AutoCAD and Civil 3D.
- Population forecasting and water demand estimation.
- Junction service-area delineation using Python and Voronoi polygons.
- Water distribution network layout and pipe sizing.
- Storage tank design and pump selection.
- Hydraulic modeling and 24-hour extended-period simulation using EPANET.
- Pressure and flow velocity analysis.
- Residual chlorine simulation and water quality analysis.
- Technical limitations and engineering considerations.

International readers are encouraged to start with the English report summary before consulting the full technical report.
