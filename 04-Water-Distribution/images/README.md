# Water Distribution Network Project Images

This folder contains selected visual outputs from the Water Distribution Network Design project in West Saadat Abad, Tehran, Iran.

## Hydraulic Analysis and Simulation

- [Pressure Distribution Map](pressure-distribution-map.png) — Spatial distribution of hydraulic pressure across the network junctions.
- [Pressure and Velocity Distribution Map](pressure-velocity-map.png) — Combined visualization of junction pressures and pipe flow velocities.
- [Pressure Time Series – Node J2](pressure-time-series-node-j2.png) — Pressure variation over a 24-hour simulation period.
- [Pressure Time Series – Node J222](pressure-time-series-node-j222.png) — Daily pressure variation at another selected network junction.
- [Junction Hydraulic Results](junction-hydraulic-results.png) — Selected tabular results, including elevation, demand, hydraulic head, and pressure.

All images were obtained from the original academic project and illustrate the hydraulic modeling, network analysis, and simulation results generated using EPANET.
