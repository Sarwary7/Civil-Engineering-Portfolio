# Water Distribution Network Project Brief

This folder contains the original academic project brief and its English translation for the Water Distribution Network Design project in West Saadat Abad, Tehran, Iran.

## Project Brief Documents

- [English Project Brief](Water-Distribution-Brief.pdf) — English translation of the original academic project requirements.
- [Original Project Brief (Persian)](Water%20distribution%20project%20outline.pdf) — Original assignment issued for the Water and Wastewater Engineering course at Amirkabir University of Technology (AUT).

The documents outline the project requirements, design criteria, hydraulic analysis objectives, EPANET simulation requirements, and relevant engineering references.

The completed project documentation and supporting files are available in their respective folders.
