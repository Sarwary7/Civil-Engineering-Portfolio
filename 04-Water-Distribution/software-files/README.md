# Software Files

This folder contains the original software files used in the Water Distribution Network Design project.

## Software

- **EPANET:** Hydraulic modeling and extended-period simulation of the water distribution network.
- **Autodesk Civil 3D:** Terrain modeling and preparation of network-related geometric data.
- **AutoCAD:** Network layout and engineering drawings.
- **Microsoft Excel:** Data processing, demand calculations, and engineering tables.
- **Python:** Service-area allocation using Voronoi polygons.

## Available Model

The original EPANET network model will be uploaded to this folder.

**File Format:** EPANET `.net`

The model includes the network components and hydraulic data used for the project analysis.

## Notes

The uploaded software files are provided for academic portfolio and demonstration purposes.
