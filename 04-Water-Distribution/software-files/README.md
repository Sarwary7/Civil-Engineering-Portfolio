# Water Distribution Network Software Files

This folder contains the original software files associated with the Water Distribution Network Design project in West Saadat Abad, Tehran, Iran.

## Software Used

- **EPANET:** Hydraulic modeling and extended-period simulation.
- **Autodesk Civil 3D:** Terrain modeling and preparation of network-related geometric data.
- **AutoCAD:** Network layout and engineering drawings.
- **Microsoft Excel:** Data processing, demand calculations, and engineering tables.
- **Python:** Service-area allocation using Voronoi polygons.
