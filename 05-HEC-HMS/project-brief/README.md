# HEC-HMS Project Brief

This folder contains the original academic project assignment and its English translation for the HEC-HMS Rainfall-Runoff Modeling project.

**Project Type:** Individual Academic Project  
**Course:** Engineering Hydrology  
**University:** Amirkabir University of Technology (AUT)  
**Date:** August 2025  
**Software:** HEC-HMS

## Project Objective

The project focuses on rainfall-runoff modeling of a hypothetical watershed using precipitation data recorded on 1 April 2004 at 15-minute intervals.

The objective is to simulate watershed outflow, calibrate the hydrological model against observed discharge data, and evaluate the sensitivity of selected model parameters.

## Project Requirements

- Development of a watershed model consisting of four subbasins, three junctions, and two main reaches.
- Definition of subbasin characteristics and precipitation inputs.
- Selection of appropriate loss, runoff transformation, baseflow, and channel routing methods.
- Manual and automatic model calibration using observed discharge data.
- Sensitivity analysis of seven hydrological parameters.
- Evaluation of peak discharge, runoff volume, hydrograph shape, peak timing, and hydrograph base time.
- Documentation of modeling assumptions, procedures, and simulation results.
