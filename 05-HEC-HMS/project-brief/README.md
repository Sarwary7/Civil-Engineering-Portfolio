# Project Brief

This folder contains the introductory documentation for the HEC-HMS Rainfall-Runoff Modeling project.

The project focuses on hydrological modeling and simulation of a hypothetical watershed with a total area of approximately 1,029 km².

The brief provides an overview of the watershed characteristics, model configuration, rainfall data, simulation methods, calibration approach, and sensitivity analysis.

**Project Type:** Individual Academic Project

**Course:** Engineering Hydrology, Amirkabir University of Technology (AUT), August 2025

**Software:** HEC-HMS

Further technical details, model files, reports, and simulation outputs are provided in their respective folders.
