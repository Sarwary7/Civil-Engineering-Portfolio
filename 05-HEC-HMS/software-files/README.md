# HEC-HMS Model and Software Files

This folder contains the original HEC-HMS project archive and supporting log files associated with the rainfall-runoff modeling, manual calibration, and sensitivity analysis project.

## Modeling Activities

- Watershed basin model development.
- Precipitation and observed discharge data preparation.
- Hydrological parameter assignment.
- Rainfall-runoff simulation.
- Manual model calibration.
- Comparison of observed and simulated discharge hydrographs.
- Evaluation of model performance using statistical indicators.
- Sensitivity analysis of seven hydrological parameters.

## Instructions for Opening the Model

1. Download the HEC-HMS model ZIP archive.
2. Extract the archive into a local directory.
3. Launch HEC-HMS.
4. Select File > Open.
5. Locate and open the corresponding `.hms` project file.
6. Review the model configuration and available simulation runs.

Preserve the original directory structure after extraction. A compatible HEC-HMS version and the required supporting data files may be necessary to reproduce the simulation results.
