# HEC-HMS Software Files

This folder contains the original HEC-HMS project files used for rainfall-runoff modeling and simulation.

## Main Software

- **HEC-HMS:** Hydrological modeling, rainfall-runoff simulation, manual calibration, and sensitivity analysis.

## Project Model Components

The original project files are intended to include:

- Basin model
- Meteorological model
- Control specifications
- Precipitation data
- Observed discharge data
- Simulation configurations

## File Information

The original HEC-HMS project files will be uploaded to this folder.

These files allow the watershed model configuration and simulation setup to be examined in HEC-HMS.
