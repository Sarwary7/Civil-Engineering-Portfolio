
# Concrete Structures Project Report

This directory contains the academic report documentation for the reinforced concrete building project conducted at Amirkabir University of Technology (AUT) – Tehran Polytechnic.

## Available Reports

| Document | Description |
|---|---|
| Concrete Structures Report Summary | A concise overview of the project, its engineering methodology, and key results. |
| Full Academic Project Report | Detailed project documentation, including structural analysis and engineering design calculations. |

## Report Coverage

- Project objectives and design requirements
- Structural configuration and modeling
- Gravity and seismic loading
- Structural analysis and design methodology
- Reinforced concrete member design
- Engineering calculations and project documentation
