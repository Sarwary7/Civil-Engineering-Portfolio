
# Concrete Structures – Software Files

This directory contains the structural analysis models, foundation design model, and CAD drawing files associated with the reinforced concrete building project at Amirkabir University of Technology (AUT) – Tehran Polytechnic.

## Engineering Software

| Software | Application |
|---|---|
| ETABS 2022 | Structural modeling, analysis, and reinforced concrete member design |
| SAFE | Foundation modeling, analysis, and design |
| AutoCAD | Structural drawings and engineering documentation |

## Available Files

| File | Format | Description |
|---|---|---|
| [ETABS Structural Model](project%20new%20model.EDB) | EDB | Reinforced concrete building model |
| [SAFE Foundation Model](safe.FDB) | FDB | Foundation analysis and design model |
| [Concrete Project Drawings](concrate%20project.dwg) | DWG | Project CAD drawings |
| [Additional CAD Drawings](44.dwg) | DWG | Supporting CAD drawing file |

## Technical Applications

- Three-dimensional structural modeling
- Gravity and seismic load analysis
- Reinforced concrete beam and column design
- Foundation analysis and design
- Structural drawing preparation

## File Compatibility

The native model and drawing files require compatible versions of ETABS, SAFE, and AutoCAD or suitable CAD viewing software.

These files are provided for academic documentation and portfolio review.
