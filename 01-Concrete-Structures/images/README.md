
# Project Images

This directory contains selected visual documentation of the Concrete Structures Project, extracted from the ETABS and SAFE structural models.

## Available Images

| Image | Description |
|---|---|
| [3D Structural Model](etabs-3d-model.png) | Three-dimensional representation of the reinforced concrete building and its structural configuration. |
| [Beam and Column Model](etabs-beam-column-model.png) | Structural framing model illustrating the arrangement of reinforced concrete beams and columns. |
| [Structural Floor Plan](structural-floor-plan.png) | Plan view illustrating the structural layout and floor framing arrangement. |
| [Foundation Model](safe-foundation-model.png) | SAFE foundation model illustrating the foundation layout and modeling configuration. |

## Software

- ETABS – Structural modeling and analysis
- SAFE – Foundation modeling and analysis

## Documentation Purpose

These images illustrate the structural configuration, beam and column arrangement, floor framing, and foundation modeling developed as part of the Concrete Structures Project.
