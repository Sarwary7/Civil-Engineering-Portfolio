# Steel Project Brief

This folder contains a concise summary of the five-storey steel building project, including its structural system, design criteria, analysis methods, and key project information.

**Project Type:** Individual Academic Project

**Structural System:** Moment-Resisting Frame

**Number of Storeys:** 5 (plus roof and penthouse levels)

**Software:** ETABS 22.7.0, SAFE 22.7.0, AutoCAD

**Design Code:** Iranian National Building Code Part 10 – Steel Structures
