
# Steel Structures Project Brief

This directory contains the English-language project brief for the individual Steel Structures Project completed at Amirkabir University of Technology (AUT).

The document summarizes the project requirements, building characteristics, structural configuration, design criteria, and engineering scope of work.

## Project Document

| Document | Description |

## Key Project Information

| Item | Details |
|---|---|
| Project Type | Individual Academic Project |
| Institution | Amirkabir University of Technology (AUT) – Tehran Polytechnic |
| Course | Steel Structures Project |
| Number of Storeys | 5, with parking, roof, and penthouse levels |
| Structural Configuration | Steel moment frames and X-braced frames |
| Roof Elevation | 20.595 m |
| Maximum Model Elevation | 23.715 m |
| Software | ETABS, SAFE, AutoCAD |
| Design Code | Iranian National Building Code – Part 10 (Steel Structures) |

The English project brief was prepared for portfolio presentation based on the academic project requirements and available structural model information.
