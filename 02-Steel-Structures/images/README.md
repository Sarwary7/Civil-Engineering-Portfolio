
# Project Images

This directory contains selected visual documentation of the Steel Structures Project, extracted from the ETABS structural model.

## Available Images

| Image | Description |
|---|---|
| [3D Structural Model](etabs-3d-model.png) | Three-dimensional representation of the steel structural system, including beams, columns, and bracing. |
| [Structural Floor Plan](structural-floor-plan.png) | Typical floor framing layout, grid dimensions, and assigned steel member sections. |
| [Moment Frame Elevation](moment-frame-elevation.png) | Elevation view of the steel moment frame in the X direction. |
| [Braced Frame Elevation](braced-frame-elevation.png) | Elevation view of the steel X-braced frame in the Y direction. |

## Software

- ETABS – Computers and Structures, Inc. (CSI)

## Documentation Purpose

These images illustrate the structural configuration, member arrangement, floor framing, and lateral framing systems developed as part of the individual academic project.
