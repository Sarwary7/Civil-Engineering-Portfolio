
# Analysis and Design Outputs

This directory contains archived documentation associated with the structural analysis and design of the steel building, developed as part of an individual academic project at Amirkabir University of Technology (AUT).

## Available Files

| File | Description |
|---|---|
| [Analysis and Design Archive](print.rar) | Archived project analysis and design documentation. |

## Analysis and Design Scope

The overall project covers:

- Structural analysis of the steel building
- Beam and column design
- Storey displacement and drift evaluation
- Steel connection design
- Foundation analysis and design
- Engineering tables and graphical outputs

Download and extract the RAR archive to access the available project documentation.
