# Software Files

This folder contains the original structural analysis and design models used in the steel structures project.

## Software

- ETABS 22.7.0 – Structural modeling and analysis
- SAFE 22.7.0 – Foundation modeling and design
- AutoCAD – Structural drawings

## File Types

- ETABS model files (.EDB)
- SAFE model files (.FDB)
- Supporting project files, where applicable
