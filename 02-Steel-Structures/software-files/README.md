
# Software Files

This directory contains the structural modeling files and supporting project archive associated with the Steel Structures Project completed at Amirkabir University of Technology (AUT).

## Available Files

| File | Format | Description |
|---|---|---|
| [SAZE.EDB](SAZE.EDB) | EDB | ETABS structural model file. |
| [SAZEE.EDB](SAZEE.EDB) | EDB | ETABS structural model used for the selected portfolio visualizations. |
| [CD.rar](CD.rar) | RAR | Supporting project file archive. |

## Engineering Software

| Software | Application |
|---|---|
| ETABS | Structural modeling, analysis, and steel member design. |
| SAFE | Foundation modeling, analysis, and design. |
| AutoCAD | Structural drawings and engineering detailing. |

## File Access and Compatibility

- Download the EDB files and open them using a compatible version of ETABS.
- Download and extract the RAR archive to access the supporting project files.
- Selected structural model visualizations were prepared using ETABS Ultimate 23.3.2.
- Software compatibility may vary depending on the original model version.

## Academic Use

These files are provided for academic documentation and engineering portfolio purposes. They are not intended for construction or commercial use without independent engineering verification.
